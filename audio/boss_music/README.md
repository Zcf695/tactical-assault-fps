# BOSS战音乐文件夹

将对应BOSS的音乐文件放入此文件夹，文件名需与下方一致。

## 音乐文件列表

| 文件名 | 对应BOSS | 风格建议 |
|--------|----------|----------|
| forest_hunter_battle.mp3 | 森林猎手·暗影 | 紧张、神秘、丛林节奏 |
| industrial_juggernaut_battle.mp3 | 工业铁卫·壁垒 | 沉重、金属感、工业节奏 |

## 音乐系统特性

- **音量渐入渐出**：进入BOSS战范围时音乐逐渐变大，离开时逐渐变小
- **距离感应**：玩家距离BOSS越近，音乐音量越大（最大80%）
- **循环播放**：音乐自动循环，直到BOSS被击杀或玩家离开
- **击杀淡出**：BOSS被击杀后音乐1秒内淡出

## 替换方法

1. 将你的音乐文件重命名为上表中的文件名
2. 放入此文件夹（audio/boss_music/）
3. 刷新游戏即可生效

## 注意事项

- 支持格式：MP3、WAV、OGG
- 建议时长：2-5分钟（循环播放）
- 建议音量：标准化到 -16 LUFS
- 如果文件不存在，游戏会静默跳过音乐播放，不影响其他功能
