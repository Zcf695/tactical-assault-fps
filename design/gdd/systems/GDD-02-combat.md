## 1. 设计目标

### 1.1 一句话目标

让玩家感觉到「**我换了一把更强的枪**」和「**我换了一套更厚的甲**」，同时保证任何配装都有明确的击杀节奏（TTK 在 0.3s–3s 区间内）。

### 1.2 可测目标

| 编号 | 目标 | 判定方式 |
|------|------|----------|
| G-01 | 38 把武器必须有可感知的差异 | 任意两把同弹药武器的 TTK 差异 ≥ 15%，或射程/散布有明显取舍 |
| G-02 | 后坐力按口径分档，同口径手感一致 | 相同 `ammo` 字段的武器 `recoil` 值完全相同 |
| G-03 | 爆头必须是高收益决策 | 爆头伤害 = 基础 × 2.5，爆头击杀所需弹数应明显少于躯干 |
| G-04 | 护甲必须有明确的档位感 | 相邻档位击杀所需弹数差 ≥ 1 发 |
| G-05 | 任何配装下 TTK 不得失控 | 对满装玩家的步枪击杀弹数 ≤ 25 发（**当前 61 发，未达成**） |
| G-06 | 武器有维护成本 | 耐久下降 → 卡壳概率上升 → 需要付费维修 |

### 1.3 不做什么

- ❌ 不做武器改装（枪口/瞄具/握把）
- ❌ 不做随机词条
- ❌ 不做部位伤害（只有「头」和「其它」两级）
- ❌ 不做弹道下坠与风偏（射线检测，无重力）

## 2. 核心循环

### 2.1 单次交火循环

```
[发现敌人] → [瞄准（腰射 / 右键 ADS）] → [开火：射线检测]
                                              ↓
                        [命中判定：先敌人后障碍，取最近]
                                              ↓
                    ┌─────────────┬───────────┴──────────┐
              命中头部         命中躯干              命中障碍
              伤害×2.5         伤害×1.0              弹孔特效
                    └─────────────┴──────────────────┘
                              ↓
                        [后坐力上抬]
                              ↓
                  [敌人死亡 → 生成战利品] 或 [继续射击]
```

### 2.2 玩家受击循环

```
[敌人开火] → [子弹飞行（90 单位/秒）] → [命中判定半径 0.837m]
                                              ↓
                     [护甲级联减伤：整体DR → 固定 → 头盔% → 护甲%]
                                              ↓
                     [扣血 + 流血判定 + 骨折判定 + 屏幕震动 + 方向指示]
                                              ↓
                              [血量 ≤ 0 → endGame(false)]
```

### 2.3 弹药经济循环

```
射击 → 弹匣 -1 → 弹匣空 → 自动换弹（可关，settings.gameplay.autoReload）
                              ↓
                     从 胸挂 → 口袋 → 背包 依次扣 1 组弹药
                              ↓
                     全部耗尽 → 无法开火 → 必须撤离或用刀
```

|------|------|------|
| 血量 | `S.health -= amt` | `game.js:2679` |
| 护甲耐久 | `S.equipment.armorHP -= armorPct × (1-degradeResist) × (1-技能)` | `game.js:2668` |

### 3.4 伤害计算顺序（护甲级联，`game.js:2635-2699`）

```
amt = raw
  ├─ ① maxTier = max(护甲tier, 头盔tier)
  ├─ ② amt ×= (1 - overallDR[maxTier])        // T4+:5% / T5:10% / T6:15%
  ├─ ③ amt  = max(0, amt - flatReduce[maxTier]) // T1~T6: 1/2/3/4/6/10
  ├─ ④ 头盔：absorb = min(helmetHP, amt × (0.30 + tier×0.05))   // 35%~60%
  │         helmetHP -= absorb × (1 - degradeResist[tier])
  │         amt -= absorb
  ├─ ⑤ 护甲：absorb = min(armorHP, amt × (0.50 + tier×0.05))    // 55%~80%
  │         armorHP -= absorb × (1 - degradeResist[tier])
  │         amt -= absorb
  ├─ ⑥ amt = max(0, min(amt, raw))            // 钳制：不超过原始伤害
  └─ ⑦ 低血量减伤（技能「不死之身」，HP<20%）：amt ×= max(0.3, 1 - 0.5)
```

> 🔴 **第 ② 步与第 ④⑤ 步叠加导致减伤过度**，见 §4.6 与 §6。

> 🟡 2,000 发才打光耐久，而一局最多带约 6 组弹药（每组 10–50 发）。**武器耐久在正常游玩中几乎不会触发**。这是一个名义系统。

### 4.9 流血与骨折

| 状态 | 触发 | 效果 | 解除 |
|------|------|------|------|
| 流血 Lv1–5 | `amt>8` 且 `rand < min(0.6, amt×0.03)`；每层独立判定 | 每秒扣 `层数 × 0.8` HP | 绷带 / 止血带 / 肾上腺素 / 医疗包 |
| 骨折 | `amt>20` 且 `rand < 0.15` 且未骨折 | 移速 -40% | 战场手术包 / 急救包 |

**流血触发概率**：

| 单次伤害 | 触发概率 |
|---------|---------|
| 9 | 27% |
| 20 | 60%（`min(0.6, 0.6)`） |
| 30+ | **60%（封顶）** |

> 🟡 伤害 ≥20 时恒定 60% 触发，等于「每两发高伤必流血」。这是否为本意待确认。

## 5. 状态机

### 5.1 武器状态

```
        ┌──────────────────────────────────────────┐
        │                 ready                    │
        └───┬──────────┬──────────┬───────────┬────┘
            │ 开火      │ 按R      │ 卡壳       │ 切枪
            ▼          ▼          ▼           ▼
        [射击帧]   [reloading] [jammed]   [switching]
            │          │           │           │
            │     计时 reloadTime  1.5s 后    切枪动画后
            │       × (1-技能)     自动解除     回 ready
            └──────────┴───────────┴───────────┘
```

| 状态 | 变量 | 阻塞什么 |
|------|------|----------|
| `reloading` | `S.isReloading` | 开火、切枪 |
| `jammed` | `S.weaponJammed` | 开火 |
| `searching` | `S._isSearching` | 开火 |
| `empty` | `S.magAmmo[slot] <= 0` | 开火（若开启自动换弹则自动 R） |

### 5.2 玩家生命状态

```
      [正常]
        │ 流血触发
        ▼
   [流血 Lv1..5] ──(绷带/止血带)──→ [正常]
        │
        │ 高伤骨折判定
        ▼
   [骨折] ──(手术包/急救包)──→ [正常]
        │
        │ HP ≤ 0
        ▼
   [阵亡] → endGame(false)
```

### 5.3 敌人 AI 状态（`enemy_ai.js`）

| 状态 | 触发 | 行为 |
|------|------|------|
| `patrol` | 默认 | 在随机目标点间移动（速度 ×0.4） |
| `chase` | 发现玩家 / 被惊动 | 向玩家移动，进入攻击距离后开火 |
| `attack` | 距离 < `attackRange` | 开火（受 `attackCd` 限制） |
| `search` | 失去视野 | 在最后已知位置附近搜索 |
| `flank` | 战术行为 | 侧翼移动 |
| `take_cover` | 被压制 | 寻找掩体 |
| `retreat` | 低血量 | 后撤 |
| `melee` | 距离 < 2m | 近战（伤害 = `damage × 0.8`，冷却 1.0s） |
| `dying` | HP ≤ 0 | 死亡动画 + 生成战利品 |

## 6. 边界与异常

| ID | 场景 | 当前行为 | 判定 |
|----|------|----------|------|
| E-01 | 弹匣空时开火 | 自动调用 `reload()`（受 `autoReload` 设置控制） | ✅ |
| E-02 | 备弹全空时开火 | `reload()` 内 `if(ammoInRig+ammoInPocket+ammoInBackpack<=0) return;` → 静默无反馈 | 🟡 无提示，玩家不知道为什么打不出子弹 |
| E-03 | 武器卡壳中切枪 | `switchWeapon` 只检查 `S.isReloading`，不检查 `weaponJammed` → **可切枪逃过卡壳** | 🟡 可被利用 |
| E-04 | 搜索中受到攻击 | `damagePlayer` 不检查 `S.phase`，正常扣血 | ✅ 符合 G-02 |
| E-05 | 护甲刚好在某发打碎 | `if(armorHP<=0){armorHP=0; armor=null;}` 当发剩余 `amt` 仍生效 | ✅ 正确 |
| E-06 | 同时穿 T6 甲和 T1 盔 | `maxTier = max(6,1) = 6` → **应用 T6 的整体 DR 与固定减伤**，但头盔按 T1 的 35% 吸收 | 🔴 头盔档位低却享受甲的高 DR |
| E-07 | 流血 5 层叠满后继续受伤 | `S.bleeding = min(5, bleeding+1)` 封顶 5 | ✅ |
| E-08 | 骨折状态下再受高伤 | `!S.fracture` 守卫，不会重复触发 | ✅ |
| E-09 | 近战武器对 T6 玩家 | 35 伤害 → 经级联吸收后 **0** | 🔴 近战对重甲完全无效 |
| E-10 | 霰弹枪 7 颗弹丸全部命中同一敌人 | 每颗独立判定，伤害累加（7×14 = 98） | ✅ |
| E-11 | 霰弹枪弹丸命中不同敌人 | 每颗独立 raycast，可同时打多个目标 | ✅ 符合预期 |
| E-12 | 敌人子弹穿过地形 | `updateEnemyBullets` 对 `obstacles` 做 AABB/球形检测（`game.js:4819-4828`） | ✅ |
| E-13 | `stim` 类型物品（兴奋剂） | `useItem()` 无 `stim` 分支 → **拾取后无法使用** | 🔴 D-16 |
| E-14 | 投掷物 | 无玩家侧投掷实现 | 🔴 D-16 |
| E-15 | 武器耐久为 0 | `dur < 30` 触发卡壳判定，但**不会损坏**，仍可射击 | 🟡 耐久 0 与耐久 29 行为相同 |
